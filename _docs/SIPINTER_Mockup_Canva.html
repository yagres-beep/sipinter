Struktur Folder Drive

Atur pola folder otomatis di Google Drive tanpa mengubah kode.

Dua bagian: Tingkat folder (hierarki induk → subfolder, "Tahun" selalu di posisi pertama & tidak dapat dinonaktifkan) dan Folder kategori (folder sejajar di dalam folder terdalam — Capaian & Bukti-Dukung-SAKIP wajib ada).
